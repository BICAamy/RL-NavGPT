由于多卡的时候，把模型拆到多张 Blackwell GPU 时会出现全零/错误 logits。

所以我们讲已经划分好的5份验证集分到5张卡上独立并行的跑：
```bash

```
由于只有4张卡，所以先跑完前4份验证集，最后再拿出一张卡跑完第5份。

#### 实验流程开始
##### 启动前四个分片
进入容器：
```bash
docker exec -it rl-navgpt bash
```
进入运行目录：
```bash
cd /workspace/RL-NavGPT/nav_src

PYTHON_BIN="/home/xl/venvs/qwen-tf448/bin/python"
BASE_DIR="../datasets/R2R/exprs/qwen2.5-14b-hf-zero-shot-shards"
```
定义启动函数：
```bash
launch_shard() {
  gpu="$1"
  shard="$2"
  output_dir="${BASE_DIR}/shard-${shard}"
  split="R2R_val_unseen_instr_${shard}"

  mkdir -p "${output_dir}"

  nohup env \
    CUDA_VISIBLE_DEVICES="${gpu}" \
    PYTHONUNBUFFERED=1 \
    TOKENIZERS_PARALLELISM=false \
    "${PYTHON_BIN}" NavGPT.py \
      --llm_backend hf \
      --llm_model_name qwen2.5-14b-instruct-1m \
      --local_model_path ../models/Qwen2.5-14B-Instruct-1M \
      --local_chat_template auto \
      --local_dtype bf16 \
      --navigation_input_mode planner \
      --output_dir "${output_dir}" \
      --temperature 0 \
      --max_new_tokens 256 \
      --max_iterations 10 \
      --val_env_name "${split}" \
      --iters -1 \
    > "${output_dir}/console.log" 2>&1 < /dev/null &

  echo "$!" > "${output_dir}/pid"
  echo "GPU ${gpu} 正在运行 shard-${shard}，PID=$(cat "${output_dir}/pid")"
}
```
分别启动：
```bash
launch_shard 0 0
launch_shard 1 1
launch_shard 2 2
launch_shard 3 3
```
每个进程只看到一张 GPU，因此不会触发错误的跨卡 device_map。

#### 合并结果
全部跑完之后
```bash
python - <<'PY'
import json
from pathlib import Path

base = Path("../datasets/R2R/exprs/qwen2.5-14b-hf-zero-shot-shards")
merged = []

for shard in range(5):
    path = (
        base
        / f"shard-{shard}"
        / "preds"
        / f"submit_R2R_val_unseen_instr_{shard}.json"
    )
    with path.open() as f:
        merged.extend(json.load(f))

ids = [item["instr_id"] for item in merged]

assert len(merged) == 2349, f"预测数量错误：{len(merged)}"
assert len(set(ids)) == 2349, "存在重复 instr_id"

output = base / "merged_predictions.json"
with output.open("w") as f:
    json.dump(merged, f, indent=2)

print(f"合并完成：{output}")
print(f"预测数量：{len(merged)}")
PY
```

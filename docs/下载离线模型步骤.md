# Qwen2.5-14B 模型下载说明

本项目使用同一个 14B 模型的两种权重格式：

- HF Safetensors：目录格式，约 29.6GB，用于 Transformers、LoRA 和
  GRPO 训练；
- GGUF Q4_K_M：单文件，约 8.4GB，用于 llama.cpp/Ollama 推理，不可
  直接用于 PEFT 训练。

不存在 `Qwen2.5-14B-Instruct-1M-Q4_K_M.hf` 这个文件：
`Q4_K_M` 只属于 GGUF 量化格式。

## 1. 下载 HF 训练权重

### 方法 A：ModelScope（当前网络推荐）

ModelScope 上的 `Qwen/Qwen2.5-14B-Instruct-1M` 是 Qwen 官方发布的同一
套 HF/Safetensors 权重。本机已安装 ModelScope CLI。下面的命令绕过当前
不稳定的本地代理，将仓库并发限制为 2；下载器支持对未完成分片进行
HTTP Range 续传：

```bash
cd /Users/bigcat/Documents/MyCode/NavGPT

NO_PROXY='modelscope.cn,.modelscope.cn,aliyuncs.com,.aliyuncs.com,localhost,127.0.0.1' \
no_proxy='modelscope.cn,.modelscope.cn,aliyuncs.com,.aliyuncs.com,localhost,127.0.0.1' \
MODELSCOPE_DOWNLOAD_TIMEOUT=120 \
MODELSCOPE_DOWNLOAD_MAX_RETRIES=10 \
caffeinate -i modelscope download Qwen/Qwen2.5-14B-Instruct-1M \
  --local-dir models/Qwen2.5-14B-Instruct-1M \
  --max-workers 2
```

已经完整下载的文件会先经过 SHA-256 校验并复用。若中途停止，重新运行
同一命令即可续传。

### 方法 B：Hugging Face 官方 Hub

仅在代理节点能够稳定访问 `huggingface.co` 时使用：

```bash
HF_HUB_DISABLE_XET=1 \
HF_HUB_DOWNLOAD_TIMEOUT=120 \
hf download Qwen/Qwen2.5-14B-Instruct-1M \
  --local-dir models/Qwen2.5-14B-Instruct-1M \
  --max-workers 2
```

如果网络稳定，也可以去掉 `HF_HUB_DISABLE_XET=1`。匿名下载被限速时，
先执行 `hf auth login`，粘贴 Hugging Face Read Token，再重复相同命令。
重复执行会跳过已经完整落盘的文件。

注意：当前本机安装的 `huggingface_hub 1.25.1` 使用进程唯一的
`.incomplete` 临时文件。中断进程后，完整分片会被复用，但未完成分片
不会跨进程续传。重新下载前可删除仅属于该模型的残留临时分片以释放空间：

```bash
find models/Qwen2.5-14B-Instruct-1M/.cache/huggingface/download \
  -type f -name '*.incomplete' -delete
```

完成后检查：

```bash
find models/Qwen2.5-14B-Instruct-1M \
  -maxdepth 1 -name 'model-*.safetensors' | sort
```

应得到 `model-00001-of-00008.safetensors` 至
`model-00008-of-00008.safetensors`，并同时存在
`model.safetensors.index.json`、`config.json` 和 tokenizer 文件。

## 2. 下载 GGUF 推理权重

```bash
HF_HUB_DISABLE_XET=1 \
HF_HUB_DOWNLOAD_TIMEOUT=120 \
hf download bartowski/Qwen2.5-14B-Instruct-1M-GGUF \
  --local-dir models \
  --include '*Q4_K_M.gguf' \
  --max-workers 4
```

当前仓库已经存在该 GGUF 文件，不需要重复下载。

## 3. 使用方式

- 本机 GGUF 推理：参见 `docs/运行命令.md`；
- Ollama 手工验证：参见 `docs/终端启动离线模型步骤.md`；
- HF/LoRA/GRPO：将 `models/Qwen2.5-14B-Instruct-1M/` 作为
  `--local_model_path`。

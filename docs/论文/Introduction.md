# 1 Introduction

Vision-and-language navigation (VLN) studies how an embodied agent can follow natural-language instructions to reach a target in a visually perceived environment. Beyond recognizing objects and rooms, a successful agent must connect multiple instruction clauses to observations, track which subgoals have been completed, recover from incorrect actions, and decide when to stop. These requirements make VLN a useful testbed for grounded reasoning and long-horizon decision making. The Room-to-Room (R2R) benchmark established this task in photo-realistic indoor environments and evaluates both goal-reaching accuracy and path efficiency (Anderson et al., 2018). Cross-modal pretraining, history-aware transformers, and topological planning have consequently become established paradigms for VLN (Hao et al., 2020; Chen et al., 2021, 2022). However, their reasoning is mostly encoded implicitly in task-specific networks, making decisions difficult to inspect and limiting direct transfer to new instructions or interaction settings.

Large language models (LLMs) provide a complementary approach because they can decompose instructions, use commonsense knowledge, and express intermediate reasoning in natural language. NavGPT demonstrates this potential by converting panoramic observations and navigation histories into text and prompting a frozen LLM to generate explicit thoughts and viewpoint actions without VLN training (Zhou et al., 2024a). Yet this design introduces two central limitations. First, translating images into captions—and later compressing observations into history summaries—inevitably discards visual details that may distinguish two candidate directions. Second, a frozen zero-shot LLM cannot improve from its navigation outcomes; mistakes such as revisiting locations, losing track of long instructions, or stopping prematurely remain outside the learning loop. Dependence on proprietary APIs further complicates reproducible and private deployment. These limitations motivate a locally deployable agent that retains NavGPT's modular and interpretable interface while learning navigation-specific behavior from direct interaction with the environment.

Existing trainable LLM-based agents mitigate this gap through supervised reasoning traces or stronger visual-policy integration (Lin et al., 2024; Zhou et al., 2024b). More recent approaches apply reinforcement post-training to end-to-end vision-language-action models or specialist VLN policies (Qi et al., 2025; Gao et al., 2026; Li et al., 2026). These advances establish reinforcement learning as a promising adaptation mechanism, but leave a different question open: can a modular, text-based navigation agent learn from environment interaction while preserving its interpretable interface and recovering visual evidence lost during captioning? Addressing this setting is valuable because modular agents allow the perception model, planner, language policy, and controller to be improved or deployed independently.

We address this question by extending NavGPT with a locally trainable decision policy. A frozen planner first converts each instruction into an action plan, which is cached and shared by all rollouts of the same task. At each decision step, the navigation policy receives this plan together with the current textual observation and trajectory history, and produces exactly one bounded `<Think>` block followed by one executable `<Action>`. This unified interface keeps the generated reasoning directly associated with the action executed in the environment. We attach LoRA adapters to the local LLM and optimize only these parameters using Group Relative Policy Optimization (GRPO), reducing trainable parameters and avoiding a separate value model (Hu et al., 2022; Shao et al., 2024). Rollouts within a GRPO group share the instruction, start viewpoint, initial orientation, and cached plan, so their relative rewards compare alternative decisions from the same initial condition.

The key component is a three-part reward that connects navigation outcomes, raw visual evidence, and generated reasoning. The navigation reward measures shortest-path progress, repeated or invalid actions, active stopping, and episode success. The semantic reward computes the change in CLIP similarity between the original instruction and raw Matterport3D views after each action (Radford et al., 2021). It therefore supplies visual supervision during training without replacing NavGPT's text-based inference pipeline. Finally, the reasoning reward evaluates whether the generated thought identifies a relevant subgoal, agrees with the selected action, and remains consistent with the current observation and navigation history. We treat the thought as an assessable policy output rather than assuming that a fluent explanation is necessarily reliable. At inference time, the training-only reward modules and GRPO are removed. The fixed perception and planning pipeline remains unchanged, while navigation decisions are produced by the frozen local LLM with its trained LoRA adapter.

Our contributions are fourfold:

1. We formulate a parameter-efficient reinforcement-learning framework for adapting a modular LLM-based VLN agent, combining a fixed instruction planner with a locally trainable navigation policy.

2. We introduce a composite navigation objective that combines geometric feedback with an auxiliary raw-visual semantic reward, directly targeting the visual information loss in NavGPT's caption-based interface.

3. We jointly optimize navigation behavior and explicit reasoning consistency through structured `<Think>/<Action>` outputs, treating language reasoning as a quantifiable and reviewable policy output grounded in observations, history, and selected actions.

4. We develop the navigation policy around an open-source local LLM, enabling fully offline inference without network access, recurring API token costs, or reliance on proprietary services. This design improves deployment autonomy and provides a practical path toward on-premise and resource-capable edge platforms.

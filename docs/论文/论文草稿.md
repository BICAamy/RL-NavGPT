# 2 Related Work

## 2.1 Vision-and-Language Navigation and Foundation-Model Agents

Vision-and-language navigation (VLN) requires an embodied agent to ground natural-language instructions in visual observations. R2R established this problem in photo-realistic Matterport3D environments (Anderson et al., 2018). Early systems combined instruction augmentation, imitation learning, and reinforcement learning, including Speaker-Follower, EnvDrop, and reinforced cross-modal matching (Fried et al., 2018; Tan et al., 2019; Wang et al., 2019). Pretraining- and memory-based models, including PREVALENT, HAMT, and DUET, subsequently introduced transferable representations, hierarchical history encoding, and online graph reasoning for generalization and long-horizon planning (Hao et al., 2020; Chen et al., 2021, 2022). These approaches encode planning implicitly in task-specific networks and depend on expert trajectories or in-domain supervision.

CLIP-Nav uses phrase-image matching for direction selection, while LM-Nav composes an LLM, CLIP, and a pretrained controller around language-extracted landmarks (Dorbala et al., 2022; Shah et al., 2023). NavGPT instead places an LLM directly in the decision loop, prompting it with textualized observations, candidate viewpoints, and trajectory history to produce explicit thoughts and actions (Zhou et al., 2024a). Its zero-shot formulation supports subgoal decomposition and progress tracking, but cannot learn from interaction; moreover, converting visual observations and long histories into compressed text causes information loss. DiscussNav and MapGPT improve frozen-model inference through multi-expert deliberation and linguistic topological memory (Long et al., 2024; Chen et al., 2024). Trainable alternatives include the parameter-efficient reasoning of NavCoT, NaviLLM's multi-task generation, and the visually aligned LLM-policy architecture of NavGPT-2 (Lin et al., 2024; Zheng et al., 2024; Zhou et al., 2024b). Our work retains NavGPT's modular interface but locally adapts its policy under a shared state-action protocol for evaluation, rollouts, and inference.

## 2.2 Cross-Modal Grounding and Visual Rewards

CLIP learns a shared image-text space that supports open-vocabulary transfer (Radford et al., 2021). In navigation, CLIP-Nav and LM-Nav use this space for direction selection or landmark grounding, while cross-modal VLN pretraining incorporates semantic alignment into learned representations (Wu et al., 2022). Related robot-learning work further treats vision-language similarity as supervision: LIV learns control-centric representations that provide dense language-conditioned rewards from images (Ma et al., 2023). However, they do not address information loss when a text-only policy consumes captioned observations.

We use CLIP differently: raw Matterport3D views form a training-only visual bypass around NavGPT's captioning pipeline. The reward is the change in instruction-image similarity after an action, rather than similarity at a single state. We therefore use the change in CLIP similarity as an auxiliary semantic reward and combine it with geometry-based navigation rewards, including distance reduction, revisit penalties, and terminal success. This design reintroduces visual supervision during training while preserving NavGPT's text-based inference pipeline.

## 2.3 Reinforcement Post-Training and Reasoning Consistency

LoRA adapts a pretrained language model by training only a small set of low-rank matrices while keeping the backbone frozen, substantially reducing the number of trainable parameters and memory cost (Hu et al., 2022). GRPO estimates relative advantages by comparing multiple outputs generated for the same input, avoiding a separate value—or critic—model and thereby reducing the memory overhead of reinforcement learning (Shao et al., 2024). Recent navigation work has adopted related reinforcement post-training. VLN-R1 maps egocentric video to continuous actions using supervised initialization followed by time-decayed reinforcement fine-tuning (Qi et al., 2025). OctoNav-R1 combines action/reasoning supervision, Nav-GRPO, and online RL for a generalist vision-language-action policy (Gao et al., 2026). NavGRPO optimizes diverse trajectory groups using success and path-efficiency signals, whereas Progress-Think jointly trains semantic progress reasoning and action prediction (Li et al., 2026; Wang et al., 2026).

Our setting is distinct from these end-to-end or specialist policies. We optimize only LoRA parameters of a local, text-based NavGPT decision model in the discrete R2R graph, while freezing perception, the planner, and environment control. Grouped rollouts share the instruction, start state, initial orientation, and cached action plan. Their reward combines navigation progress, raw-visual semantic progress, and explicit checks of subgoal relevance, thought-action agreement, and consistency with observations and history. Accordingly, we treat the generated reasoning as an explicit and assessable policy output rather than assuming that it is always reliable. Our reinforcement-learning objective jointly optimizes navigation behavior and the consistency of the generated reasoning with the selected action, current observation, and navigation history.

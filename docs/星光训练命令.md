# NavGPT GRPO 正式 1000-step 训练命令

本文件是当前唯一正式训练命令。旧的 2-GPU、750-step、1500-step、
`semantic-potential-scale=4`、512-token validation 和 `tmux` 命令均已废弃。

正式实验固定为：

- 基础模型：`Qwen2.5-14B-Instruct-1M`；
- 4 张 NVIDIA A100 80GB，NCCL profile 为 `default`；
- 1000 个 optimizer steps，每个 step 生成 4 条 rollout，共 4000 条；
- step 100、200、……、1000 保存 10 个恢复 checkpoint；
- 同步建立 10 个不可变 LoRA evaluation snapshot；
- 每个 snapshot 运行 Val-Unseen-128 fast validation；
- 训练结束后，严格检查候选集合恰好为上述 10 个 step；
- 依次运行 10 次 256-token、2349 条 native full Val-Unseen；
- 所有 fast/full job 进入同一个可恢复 evaluation queue；
- 使用正式 SPL-first 选择规则产生唯一 `full_best`。

训练期间不要修改、替换或 `git pull` 当前项目代码、模型、数据、cache 和
annotation。运行身份会绑定这些输入的哈希。

## 3. 启动正式训练

持续查看日志：


正常生命周期如下：

- 每个 optimizer step 增加 4 条 rollout；
- step 100、200、……、1000 会暂停训练并运行 128 条 fast validation；
- step 1000 fast 完成后进入 train-end full 阶段；
- full 阶段按 step 100 到 1000 顺序运行 10 个 2349 条评估；
- full 阶段可能持续约两天以上，此时 rollout 数保持 4000 属于正常现象；
- 不要因为训练进度条已经到 100% 就终止进程；必须等待 `.exit` 出现且为 0。

## 6. 中断后的恢复

恢复前不要改代码，也不要创建新输出目录。启动脚本会自动先恢复当前
checkpoint 对应的 pending fast/full event，再继续 optimizer 或完成 train-end。

```bash
set -euo pipefail

cd ~/.bihu/rl-navgpt/RL-NavGPT

RUN_DIR="$(cat /tmp/navgpt-formal-1000-output-dir)"
COMMAND_FILE="$(cat /tmp/navgpt-formal-1000-command-file)"

CHECKPOINT="$(
  find "$RUN_DIR" -maxdepth 1 -type d -name 'checkpoint-*' -print |
    sort -V |
    tail -n 1
)"

test -n "$CHECKPOINT"
test -d "$CHECKPOINT"
test -x "$COMMAND_FILE"

RESUME_TAG="resume-$(basename "$CHECKPOINT")-$(date -u +%Y%m%d-%H%M%S)"
RESUME_LOG="${RUN_DIR}.${RESUME_TAG}.console.log"
RESUME_EXIT="${RUN_DIR}.${RESUME_TAG}.exit"
RESUME_PID_FILE="${RUN_DIR}.${RESUME_TAG}.pid"

nohup setsid --fork --wait bash -c '
  set +e
  command_file=$1
  checkpoint=$2
  exit_file=$3

  printf "===== RESUME START %s checkpoint=%s =====\n" \
    "$(date -Is)" "$checkpoint"
  bash "$command_file" --resume-from-checkpoint "$checkpoint"
  code=$?
  printf "===== RESUME END EXIT=%s %s =====\n" "$code" "$(date -Is)"
  printf "%s\n" "$code" > "$exit_file"
  exit "$code"
' bash "$COMMAND_FILE" "$CHECKPOINT" "$RESUME_EXIT" \
  > "$RESUME_LOG" 2>&1 < /dev/null &

RESUME_PID=$!
printf '%s\n' "$RESUME_PID" > "$RESUME_PID_FILE"
printf '%s\n' "$RESUME_LOG" > /tmp/navgpt-formal-1000-console-log
printf '%s\n' "$RESUME_PID" > /tmp/navgpt-formal-1000-pid
printf '%s\n' "$RESUME_EXIT" > /tmp/navgpt-formal-1000-exit-file

echo "CHECKPOINT=$CHECKPOINT"
echo "RESUME_PID=$RESUME_PID"
echo "RESUME_LOG=$RESUME_LOG"
echo "RESUME_EXIT=$RESUME_EXIT"

sleep 10
tail -n 120 "$RESUME_LOG"
```

不要添加 `--resume-implementation-patch-reason`。该参数只用于经过独立审计的
实现级修复，不允许用它绕过普通配置或代码不一致。

## 7. 正式完成验收

只有主启动或最后一次恢复的退出码为 0，且以下审计通过，训练才算完成。

```bash
set -euo pipefail

cd ~/.bihu/rl-navgpt/RL-NavGPT
RUN_DIR="$(cat /tmp/navgpt-formal-1000-output-dir)"
ACTIVE_EXIT_FILE="$(cat /tmp/navgpt-formal-1000-exit-file)"

test -f "$ACTIVE_EXIT_FILE"
test "$(cat "$ACTIVE_EXIT_FILE")" -eq 0
echo "FINAL_EXIT=0"

python - "$RUN_DIR" <<'PY'
import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path.cwd() / "nav_src"))
from r2r_evaluation import selection_key

run = Path(sys.argv[1]).resolve()
expected_steps = list(range(100, 1001, 100))

rollout_path = run / "logs/navigation_rollouts.jsonl"
rollout_count = sum(1 for line in rollout_path.open() if line.strip())
assert rollout_count == 4000, rollout_count

checkpoint_steps = sorted(
    int(path.name.removeprefix("checkpoint-"))
    for path in run.glob("checkpoint-*")
    if path.is_dir()
)
assert checkpoint_steps == expected_steps, checkpoint_steps

snapshot_steps = sorted(
    int(path.name.removeprefix("step-"))
    for path in (run / "validation/snapshots").glob("step-*")
    if path.is_dir()
)
assert snapshot_steps == expected_steps, snapshot_steps

queue = json.loads((run / "validation/queue.json").read_text())
state = json.loads((run / "validation/state.json").read_text())

assert all(row["status"] == "completed" for row in queue["events"])
assert all(row["status"] == "completed" for row in queue["jobs"])
assert [row["step"] for row in state["fast_history"]] == expected_steps

fast_jobs = [row for row in queue["jobs"] if row["mode"] == "fast"]
full_jobs = [row for row in queue["jobs"] if row["mode"] == "full"]
assert [row["step"] for row in fast_jobs] == expected_steps
assert [row["step"] for row in full_jobs] == expected_steps
assert all(row["result"]["count"] == 128 for row in fast_jobs)
```

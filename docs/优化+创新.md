### 核心主方案：GRPO 轻量化微调 + 三类复合奖励优化 + 思考 - 动作协同范式

**定位**：

​	本方案为论文核心创新主体，在 NavGPT 模块化架构基础上，通过强化学习实现 LLM 规划能力的轻量化提升，同时针对性解决视觉转译信息损失、推理过程不可控两大核心痛点，形成三层递进的创新体系。

#### 可解决的核心痛点

1. 痛点 1：视觉转文本信息损失（NavGPT 原文明确的最大性能瓶颈）
2. 痛点 2：长指令目标遗忘、走回头路、规划稳定性差
3. 痛点 3：零样本 LLM 无任务专属学习能力，规划质量波动大
4. 痛点 4：LLM 决策黑盒化，思考过程无约束，可解释性不足

#### 整体框架嵌入点

```
【输入】用户导航指令
    ↓
【固定 Planner】用户指令→action plan（当前主实验默认；原始指令作为消融）
    ↓
【MLLM】摄像头2D图→场景文本描述（完全不动，与原版NavGPT一致）
    ↓
【辅助模块】CLIP视觉编码器→提取当前观测视觉特征（新增）
    ↓
【核心优化对象：LLM决策层】（RL仅优化此处LoRA参数）
    输入：planner action plan + 当前场景文本描述 + 历史路径记录
    输出：<Think>推理思考过程</Think> + <Action>高层规划动作
    ←【RL优化模块】：GRPO算法 + 三类复合奖励函数，同步优化思考质量与动作准确率
    ↓
【底层控制】动作转电机指令→仿真/真实环境执行（完全不动，与原版NavGPT一致）
    ↓
【闭环反馈】执行结果→新画面→MLLM转文本 + CLIP提特征→喂给LLM；同时将「动作好坏+思考质量+语义匹配度」传给RL模块做奖惩
```

这里的“固定 Planner”指完整的规划模块：禁用 LoRA 的
Qwen2.5-14B 基础模型、`nav_src/prompt/planner_prompt.py` 中的
`PLANNER_PROMPT`、原生 Chat Template，以及固定为 temperature=0 的
解码配置。它不只是一个提示词字符串。

正式训练前，用固定 Planner 将已经下载好的 R2R 原始 instruction 转换成
action plan，并按 `instr_id` 另存为派生 JSON/JSONL。这叫“离线缓存
action plan”：缓存的是模型生成结果，不是重新下载或复制 R2R 数据集。
这样做可以避免每个 epoch、每个 GRPO group 都重复生成计划，确保同一
任务的多个 rollout 获得完全相同的初始状态，并防止 Planner 随策略 LoRA
一起更新而造成训练状态漂移。

该处理没有删除用户指令信息，而是延续 NavGPT 的层级规划结构；直接输入
原始 instruction 保留为消融实验，用于验证 Planner 拆解的贡献。

当前代码使用预生成场景文本，CLIP 分支需要额外读取原始视觉视图。正式
训练推荐离线缓存每个 viewpoint/朝向的 CLIP 图像特征，仍然直接从视觉
信号计算奖励，不以场景文本替代视觉特征。

#### 复合奖励函数设计

奖励分为三大类，加权求和后作为单步总奖励，同步引导模型优化导航效率、语义一致性与推理质量。

| 奖惩大类               | 奖惩类型       | 触发条件                                     | 奖励 / 惩罚数值                    | 解决的具体问题                                               |
| ---------------------- | -------------- | -------------------------------------------- | ---------------------------------- | ------------------------------------------------------------ |
| **基础导航奖励**       | 最终成功奖励   | 机器人成功到达目标终点，SR 达标              | +100 ~ +300                        | 让 LLM 学会以最终目标为导向，从根源避免目标遗忘              |
|                        | 路径效率奖励   | 执行移动后最短路径距离发生变化               | `5 × (d_prev - d_cur)`             | 连续奖励靠近、对称惩罚走远；整段和最终 endpoint 距离对齐     |
|                        | 回头路惩罚     | 踏入已访问过的节点 / 位置                    | -10 / 步                           | 直接惩罚重复路径，快速降低走回头路的概率                     |
|                        | 无效动作惩罚   | 连续 3 步原地打转、无意义转向或撞墙          | -20                                | 抑制无效规划，提升决策稳定性                                 |
|                        | 指令偏离惩罚   | 路径未经过指令要求的关键地标 / 子目标节点    | -50                                | 强化长指令下的关键节点记忆，避免偏离任务要求                 |
|                        | 失败惩罚       | 导航超时、走进死胡同无法继续                 | -80                                | 惩罚完全错误的规划，引导模型避开无效路径                     |
|                        | 子目标完成奖励 | 每成功完成一个指令拆解的子目标               | +30                                | 引导模型分步执行，匹配长指令拆解逻辑                         |
| **跨模态语义对齐奖励** | 语义匹配奖励   | 当前视觉观测与指令描述的 CLIP 特征相似度提升 | +3 ~ +8 / 步（与相似度增量正相关） | 弥补视觉转文本的信息损失，让 RL 不仅优化 “走得近”，更优化 “语义上符合指令描述” |
| **思维质量奖励**       | 子目标对齐奖励 | 思考内容中的子目标拆解与指令要求一致         | +5 / 步                            | 约束思考过程贴合任务，避免无关推理                           |
|                        | 动作一致性奖励 | 思考中的决策理由与最终输出动作逻辑自洽       | +5 / 步                            | 强化 “先想后做” 的协同性，提升决策可解释性                   |
|                        | 逻辑矛盾惩罚   | 思考内容与当前观测 / 历史轨迹存在事实矛盾    | -8 / 步                            | 抑制幻觉式推理，提升思考过程的真实性与可靠性                 |

#### 三层创新价值

1. **基础层创新**：

   ​	首次提出面向模块化 LLM 导航的轻量化 GRPO 微调范式，仅训练 LoRA 参数即可大幅提升规划稳定性，兼顾性能与泛化性。

2. **核心算法创新**：

   ​	提出跨模态语义对齐奖励函数，直接从原始视觉信号计算匹配度，弥补了 “视觉→文本” 转译过程中的信息损耗，针对性突破 NavGPT 的原生性能瓶颈。

3. **范式级创新**：

   ​	实现思考 - 动作协同优化的 RL 训练范式，不仅优化动作输出，更同步约束思考过程的逻辑性与一致性，让 LLM 导航的推理过程可控、可解释，为后续人机交互、安全校验提供基础。

### 方案 2：视觉 - 语言对齐的 RL 闭环优化（后续扩展方向）

可解决：痛点 1（视觉转文本的信息损失）的深度优化

方向说明：在当前语义对齐奖励的基础上，进一步将 MLLM 视觉编码器也纳入 RL 微调闭环，实现端到端的视觉 - 语言 - 动作联合对齐，进一步缩小与端到端 VLN 模型的性能差距。

### 方案 3：实时反馈的 RL 纠错（后续扩展方向）

可解决：纯 Prompt 式 LLM 规划滞后、纠错不及时的问题

核心思路：

纯 Prompt 的 LLM，只有走完一步、发现完全错了，才会回头重规划；本方案用 RL 训练 LLM 学会实时纠错：每走一步就通过环境反馈判断当前规划合理性，异常时立刻修正，无需等走错后再回溯。

**核心实现方式：**

1. 给 LLM 输出新增「当前规划置信度」字段，让模型每一步评估当前规划的可行性；

2. 用 RL 优化置信度判断与纠错策略，以纠错后的路径效率、最终成功率为奖励信号；

3. 让模型在仿真中自主试错，学会动态调整规划时机与策略，而非依赖固定的 “每 N 步核对一次” 规则。

   RL 算法选择：GRPO
